## 특별히 조심할 것

- **사실과 출처**: 11부와 14부는 역사와 사람이 중심이다. 날짜, 장소, 누가 무엇을 했는지, 인용은 기록으로 확인된 것만 쓰고 `sources`에 적는다. 지어낸 장면, 대사, 속마음은 쓰지 않는다.
- **해석은 공정하게**: 11부에서 한 해석을 정답처럼 쓰지 않는다. 각 해석이 무엇을 설명하고 무엇을 대가로 치르는지 나란히 보여 준다.
- **14부의 무게**: 피해와 희생자 수는 정확한 출처의 숫자를 쓰고, 차분하고 진지하게 쓴다. 무기 설계를 따라 할 수 있을 만큼 기술적으로 자세히 쓰지 않는다. 원리 수준(연쇄 반응, 임계 질량이라는 생각)까지만 쓴다.
- **어려운 과학**: 12부의 시간 지연, 길이 수축 계산은 중학생이 따라올 수 있게 그림, 숫자, 기호 순서로 쓴다.
