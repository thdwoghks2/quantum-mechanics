# 세션 다섯 개로 나눠 하는 작업

작업을 다섯 세션이 동시에 나눠 한다. 세션마다 고칠 파일이 정해져 있어서 서로 부딪히지 않는다.
각 세션은 이 문서와 자기 번호의 문서(`session-1.md` ~ `session-5.md`)를 읽고 시작한다.

| 세션 | 맡은 일 |
|---|---|
| 1 | 2~7강을 새 말투와 속도 규칙으로 다시 쓰기 |
| 2 | 8~13강을 새 말투와 속도 규칙으로 다시 쓰기 |
| 3 | 14~20강을 새 말투와 속도 규칙으로 다시 쓰기 |
| 4 | 디자인 손보기, 보상 설계 만들기, 화면 문구 정리 |
| 5 | 21~24강 새로 쓰기, 인물·연대기·커리큘럼 자료 정리 |

## 모든 세션이 지킬 것

1. **서브에이전트(Agent 도구)와 Workflow 도구는 쓰지 않는다.** 모든 작업을 그 세션에서 직접 한다.
2. **출발점**: `origin/claude/great-darwin-0g3mr0`에서 시작한다.
   ```sh
   git fetch origin claude/great-darwin-0g3mr0
   git checkout -B <이 세션에 지정된 작업 브랜치> origin/claude/great-darwin-0g3mr0
   npm ci
   ```
   푸시는 이 세션에 지정된 작업 브랜치로만 한다. `claude/great-darwin-0g3mr0`, `main`, 기본 브랜치에는 푸시하지 않는다. PR은 만들지 않는다. 합치기는 원래 세션이 한다.
3. **자기 파일만 고친다.** 세션 문서의 "고치는 파일"에 없는 파일은 고치지 않는다. 꼭 고쳐야 하면 고치지 말고 끝 보고에 적는다.
4. **기준 문서**: `docs/STYLE.md` 전체(특히 2장 목소리, 2-3 속도와 밀도, 4장 용어 계약), `docs/ADDING_CONTENT.md`.
   **본보기**: 1강 `src/content/lessons/00-basics/001-what-physics-does.mdx`. 새 말투와 속도 규칙을 모두 지킨 강이다. 1강은 고치지 않는다.
5. **푸시 전에 검사**: 아래가 모두 통과해야 한다. 문체 검사는 내 파일에서 경고 0건이어야 한다.
   ```sh
   npm run validate
   npm run lint:style
   npm test
   npm run build
   ```
6. **커밋**: 영어 명령형 제목 한 줄과 필요한 본문. 모델 이름은 적지 않는다. 일의 단위마다(예: 강 하나마다) 커밋하고, 끝나면 푸시한다.
7. **끝 보고**(세션 마지막 메시지): 작업 브랜치 이름, 커밋 목록, 바꾼 것 요약, 사실 확인이 더 필요한 곳, 내 파일 밖에서 고쳐야 할 것.

## 1강 검토에서 실제로 걸린 실수 (다시 쓰는 세션 1, 2, 3, 5)

1. 한 번에 보이는 글이 4문장 넘음, 화면 하나에 5~7문장. → 3문장까지, 넘으면 `<S n={2}>`로 나누거나 화면을 쪼갠다
2. 60자 넘는 문장이 많음. → 60자 안팎, 75자를 넘기지 않는다(`<Key>`만 예외)
3. "~어요."로 끝나는 문장이 일곱 번 이어짐. → "~거든요"(이유), "~잖아요"(같이 아는 것), "~죠"(확인), "~이에요"를 섞는다
4. `<Key>`가 짧은 선언 + 예시 두 문장. → 조건과 이유를 다 담은 한 문장
5. 가장 중요한 문장에 어려운 말("~위에서 성립", "곧", "꿰다"). → 쉬운 말
6. 학문을 사람처럼("물리학이 예측했다"), 직함을 이름 앞에 쌓기("영국의 물리학자 아이작 뉴턴이"). → "사람들이 그 법칙으로 예측했어요", "아이작 뉴턴은 ~"
7. 질문을 던지고 답을 다음 화면으로 미룸. → "왜 그럴까요?" 바로 다음 문장에서 답한다
8. `<Note>`를 덧붙이는 사실에 씀. → 아이들이 실제로 헷갈리는 곳에서 멈춰, 다른 예로 다시 짚을 때만. 한 강에 한두 개
9. 정의 화면 글이 정의 카드를 되풀이. → 앞 화면과 이어서 왜 이 이름이 필요한지
10. 확인 문제에 필요한 조건이 빠짐(복습 목록에 혼자 실리면 못 풂). → 문제 글 안에 조건을 다 담는다
11. 마지막 점검이 강에서 안 가르친 지식(요리 상식)을 물음. → 오늘의 원리로 생각하는 짧은 문제 하나, 힌트 한두 개
12. 해를 맨눈으로 보라는 말처럼 읽힘. → 위험한 행동에는 안전 문구
13. 대화하듯, 혼잣말처럼 쓰는 건 한 강에 두세 번까지만. 바탕은 가르치는 목소리
