먼저 `docs/handoff/README.md`를 끝까지 읽는다. 브랜치, 검사, 보고, 고칠 수 있는 파일은 거기 정한 대로 한다.

## 맡은 것

- **다시 쓰기**: 2~20강(`src/content/lessons/00-basics/002`~`008`, `01-waves/009`~`020`)
- **새로 쓰기**: 21~36강(2부 "열과 빛", 폴더 `02-heat-light`)

순서는 다시 쓰기부터 한다(뒤 강들이 이 강들 위에 선다).

## 다시 쓰기 (2~20강)

1강과 같은 수준으로 말투, 속도와 밀도, 구성을 바꾼다.

- 내용은 그대로 둔다: 물리, 숫자, 시뮬레이션, 그림, 문제 id, `testout`, `sources`, `assumes`, `introduces`
- 모든 화면에 `title`을 붙인다.
- 강 끝은 되짚기(`<Recap>`) → 마지막 점검(기존 `<DailyProblem>` id 그대로, 짧은 생각 문제 하나) → 한 문장으로(`<OneLine>`) → 다음 강으로. `<ThreeLines>`는 없앤다.
- `question`은 "~까요?"로 쓰고, `mechanism`은 해요체로 쓴다.
- 17강 제목("빛의 색은 진동수로 정해진다")은 "빛의 색과 진동수"로 바꾼다. 강 파일의 `title`, `short`와 `curriculum.yaml`을 함께 바꾼다.
- 용어집 2~20강 구역: `examples`와 `notThis`는 해요체로, `definition`은 쉬운 말로 바꾼다. id, `taughtIn`, `q`, `highlight`, `unit`, `aliases`, `pattern`은 그대로 둔다.
